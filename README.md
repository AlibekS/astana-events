# Афиша Астаны

Минималистичная афиша событий Астаны на ближайшие 15 дней: концерты, театр и балет, выставки, стендап и шоу.
Полностью статический сайт на GitHub Pages — без серверов, баз данных и рекламы.

## Как это устроено

```
GitHub Actions (cron, каждые 6 ч)          GitHub Pages
┌───────────────────────────────┐          ┌──────────────────────────────┐
│ scraper/parse_astana.py       │  commit  │ index.html + assets/         │
│  · sxodim.com/astana          │ ───────► │ fetch('data/events.json')    │
│  · ticketon.kz/astana         │          │ фильтры в памяти браузера    │
│  → data/events.json, meta.json│          └──────────────────────────────┘
└───────────────────────────────┘
```

* **Парсер** обходит рубрики источников, читает со страницы события структурированные данные
  (`schema.org/Event`): дату, время, все сеансы, цену, адрес, постер и ссылку на покупку билетов.
* **Гео-фильтр**: только `addressLocality = Астана` + стоп-слова других городов в адресе.
* **Окно**: от сегодня до +14 дней (ровно 15 дней). Длительные события (выставки) хранятся с `end_date`
  и показываются в каждый день своего периода.
* **Защита данных**: если источники не ответили или вернули меньше 35 % от прошлого объёма,
  `events.json` не перезаписывается. Если события не изменились — коммита нет.

## Интерфейс

* **Лента дат** (sticky): текущая неделя (прошедшие дни приглушены) + 15 дней вперёд.
  В каждой ячейке — мини-постеры событий дня и счётчик, выходные подчёркнуты.
* **Режим «Календарь»** — та же лента раскладывается в сетку 7 × 3 с превью событий на каждый день.
* Категории, поиск по названию/площадке и переключатель «Бесплатно» мгновенно пересчитывают и карточки,
  и превью в календаре.
* Карточка → окно с деталями (на телефоне — bottom-sheet со свайпом вниз): постер, время, адрес,
  ссылки на 2GIS и Google Maps, описание и кнопка «Перейти к билетам». Клик по постеру в окне и кнопка
  «Билеты» на карточке ведут сразу на страницу покупки.
* Светлая и тёмная темы «Liquid Glass», выбор запоминается; по умолчанию — системная тема.
* Состояние в URL: `?d=2026-11-21&c=concerts&q=jazz&free=1`, детали события — `#sx_12345`.

## Структура

```
.github/workflows/update-events.yml  сбор данных по cron + деплой на Pages
scraper/parse_astana.py              парсер (Python 3.11, httpx + BeautifulSoup)
data/events.json, data/meta.json     автогенерируемые данные
assets/css/themes.css                токены светлой/тёмной темы
assets/css/glass.css                 стекло, календарь, карточки, адаптив
assets/js/app.js                     загрузка, рендер, тема, модальное окно
assets/js/calendar.js                лента/сетка дат (UTC+5, от текущей недели)
assets/js/filters.js                 фильтрация по дате, категории, поиску
index.html
```

## Запуск локально

```bash
pip install -r scraper/requirements.txt
python scraper/parse_astana.py          # обновит data/
python -m http.server 8000              # http://localhost:8000
```

## Публикация на GitHub Pages

1. Слить ветку в `main`.
2. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
3. **Actions → «Update events & deploy» → Run workflow** — первый сбор и публикация.
   Дальше всё обновляется само каждые 6 часов.

Сайт будет доступен по адресу `https://<user>.github.io/astana-events/`.

## Источники

| Источник | Статус |
|---|---|
| [sxodim.com/astana](https://sxodim.com/astana) | основной: карточки, сеансы, цены, ссылки на билеты |
| [ticketon.kz/astana](https://ticketon.kz/astana) | подключён, но сайт закрыт защитой Cloudflare от автоматических запросов; если защита пропустит запрос, события подхватятся автоматически, иначе источник тихо пропускается |

Новый источник — это функция `source_<name>(window, max_pages) -> list[Event]`, добавленная в словарь `SOURCES`.
